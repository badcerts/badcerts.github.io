# Visual grammar for the evidence atlas

The earlier analytical-format experiments are a library of possible explanations, not data. Twenty screened candidates are supplied in `format-candidates.public.json`; the original private decks and proof PDF are deliberately not included. This specification carries their useful visual semantics forward without importing stale wording or private metadata.

## Reading surface

Use a light technical reading surface. Suggested palette: paper `#F4F5EF`, white `#FFFFFF`, primary ink `#163336`, secondary ink `#52666A`, rules `#D1DCD7`, teal `#007C83`, blue `#176DA5`, ochre `#98611A`, violet `#68568D`. Treat these as design references; verify contrast for actual font size and background. Never rely on hue alone for a research state.

Use a locally available/system sans serif for interface and body text, and a local monospace stack for identifiers and numbers. Avoid remote fonts. Keep long-form lines near a comfortable reading width and body type readable in print. Reserve dark panels for a small number of conceptual diagrams if useful; do not turn the report into a dark dashboard.

Use modest section numerals, clear table rules and generous paragraph spacing. Narrative, numeric table and claim limits form one reading unit. No hero slogan, fake live status, decorative performance gauge or marketing card grid.

## Core plates

|---|---|---|
| C01 Missingness matrix | Rows for early audit, six summaries, native pair, field history and observer; columns for available bytes, measurement and sensitivity | Literal categories or patterns. Missing artifact, inspected absence and unmeasured quantity are separate. No strength heat scale |
| C02 Hypothesis episodes | Proposal, narrowed negative, correction, bounded measurement and open continuation | Ordered history, not a measured confidence trajectory. Use dates only when supplied; otherwise categorical stages |
| C03 Argument map | Data, warrant, assumption, alternative and bounded claim for R05 and R18 side by side | The arrow documents reasoning; it does not authenticate its premise |
| C04 Observation tracks | `data/observation-tracks.public.json`, indexed by actual completion position | Unscored prefix, first occurrence and repeated occurrence use both labels/patterns and color. No secret-membership or time encoding |
| C05 Source-to-claim rows | Disclosed source field, technical reading, permitted inference, unresolved alternative | Interpretation is not literal translation. Keep one source route per argument |
| C06 Artifact exchange | One retained pair feeds key-holder analysis, analytical review and keyless observer | An event/file schematic inspired by interaction diagrams. No amplitudes, measured duration, process IDs or independent-sample implication |
| C07 Shared-input map | Shared trace/profile/code nodes connect actual checks | A categorical dependency graph inspired by tensor/bipartite layouts. No bond weights, covariance or entanglement claim |
| C08 Provenance cutaway | Bytes, export/container, profile/tokenizer, verifier and permitted claim layers | Conceptual layers, not a universal causal pipeline or confidence elevation |

## Concrete artifact-exchange content

Draw one retained native clean/marked pair as the shared originating event. Show these later checks as separate operations on that same material:

1. Local key-holder reanalysis: actual membership under the retained construction and keys; October 7, 23:26 UTC.
2. Analytical review: recounts, arithmetic and interpretation from shared records; no additional generation.
3. Peer-reported second-architecture observer: nonsecret count/arithmetic route, expected output supplied; October 8 return/review.

Earlier external-runtime inference is a distinct historical branch, with source and quality limitations. It must not be mistaken for the October observer or credited with the local key-holder result. Caption the diagram **schematic event order; shared inputs; no independent generation implied**.

## Figure requirements

- Give every figure an ID, descriptive title, source route, observation unit and claim-limit caption.
- Provide descriptive prose in document reading order. Alt text supplements rather than replaces that explanation.
- Keep numbers searchable; raster-only labels are insufficient.
- Ensure all figures work in grayscale. Use explicit labels, symbols, borders or patterns.
- Use exact integer counts and supplied precision. Do not infer more precision, measured time, confidence, utility or information gain.
- Align plots only when their axes mean the same thing. Earlier field throughput/memory observations need separate units and small-batch limitations if charted.
- Use diagrams to explain specific questions. C12-C20 remain available according to their supplied statuses; deferred quantitative encodings must not be promoted without measured inputs.

The novel use of a format is welcome when its new semantics are explicit. A persuasive-looking network, barcode or physical metaphor cannot supply missing evidence.
